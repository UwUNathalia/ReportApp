# Report App

Aplicación Android (Kotlin) para que los ciudadanos reporten problemas de infraestructura urbana
(huecos, basura, alumbrado dañado) con foto y ubicación GPS, y sigan el estado de sus reportes.

## Estado actual
- Estructura base del proyecto (Gradle Kotlin DSL, ViewBinding, Material 3).
- Tema con la paleta de la presentación.
- Soporte de idiomas: inglés (`values/`) y español (`values-es/`), según el idioma del celular.

## Cómo abrirlo
1. Abrir la carpeta en Android Studio (Koala o superior).
2. Esperar la sincronización de Gradle.
3. Ejecutar en un emulador o celular con Android 8.0 (API 26) o superior.
